# Från råtext till semantisk html
Din uppgift är att förvandla texten i radata.txt till en semantiskt korrekt webbsida. Du får inte ändra själva textinnehållet, men du ska bygga HTML-skelettet runt det.

# Krav för godkänt:

• Sidan ska ha ett korrekt HTML5-skelett (doctype, html, head, body).

• Innehållet ska vara logiskt uppdelat med `<header>`, `<main>` och `<footer>`.

• Texten ska ha minst en huvudrubrik `<h1>` och relevanta underrubriker ex. `<h2>` eller `<h3>`.

• Minst en uppräkning i texten ska formateras som en riktig lista (`<ul>` eller `<ol>`.

• Koden får inte innehålla någon "Div-soppa" – använd `<div>` enbart om du redan nu vill förbereda för specifik CSS-layout.

# Inlämning:

Lämna in uppgiften genom att länka till er egna repository.

**Uppladdning av html-fil accepteras inte!**
